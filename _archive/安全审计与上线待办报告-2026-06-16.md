## 一、安全漏洞（上线前必须修复）

### 🔴 S-1：API 路由缺乏服务端鉴权

**严重程度:** 高危  
**涉及文件:**
- `src/app/api/articles/route.ts` — POST（创建文章）、DELETE（删除文章）
- `src/app/api/videos/route.ts` — POST、DELETE
- `src/app/api/upload/image/route.ts` — POST

**问题描述:** 目前管理员身份只在**浏览器端**靠 `localStorage` 判断：
```typescript
// src/lib/auth.ts — 纯客户端检查
export function isAdmin(): boolean {
  return getCurrentUser()?.role === 'admin'
}
```
任何人打开浏览器开发者工具，运行 `localStorage.setItem('cxl_user', '{"role":"admin"}')` 就能调用管理 API 创建/删除文章、视频，上传任意文件。文章和视频的 API 路由完全没有验证请求方是否已登录、是否为管理员。

**修复方案:** 在文章、视频、上传 API 中添加服务端鉴权逻辑。利用 Next.js 的 `cookies()` 或请求头验证。最简单的方案：
- 登录时返回一个签名 token（JWT 或简单 HMAC）
- 每次管理 API 请求携带该 token
- 在 API 路由中验证 token 有效性及 role 是否为 admin

### 🟡 S-2：Footer 管理链接暴露

**严重程度:** 中低  
**涉及文件:** `src/app/components/layout/Footer.tsx` 第94行

**问题描述:** Footer 底部始终显示"管理"链接指向 `/admin/articles`，所有访客都能看到。但实际访问时会先走前端 `useEffect` 鉴权——未登录会显示"需要管理员权限"页面，不会直接泄露内容。

**修复方案:** 转为只在登录后显示（需要将 Footer 改为客户端组件），或直接删除该链接（管理员可以通过浏览器地址栏手动访问后台）。

### 🟡 S-3：登录无 token 无过期机制

**严重程度:** 中  
**问题描述:** 登录成功后，直接将用户信息（含 role）明文存入 `localStorage`：
```typescript
localStorage.setItem(AUTH_KEY, JSON.stringify(data.user))
```
- 无签名验证，任何人都能伪造
- 无过期机制，永不过期
- 无安全 Cookie / HttpOnly

**修复方案:** 同 S-1，引入 token 机制即可一并解决。

### 🟢 S-4：上传接口无身份验证

**严重程度:** 中  
**涉及文件:** `src/app/api/upload/image/route.ts`、`src/app/api/upload/video/route.ts`

**问题描述:** 任何人都可以直接 POST 上传文件到服务器，只检查了文件类型和大小，没验证是否登录、是否是管理员。可作为攻击者灌垃圾文件的入口。

## 二、功能缺陷（建议上线前修复）

### 🟡 F-1：联系表单数据无法在后台查看

**当前:** 提交的数据存在 `data/contacts.json`，管理员只能在服务器上打开文件看。  
**建议:** 在管理后台添加"联系表单"页面，查看、标记已处理、删除留言。

### 🟡 F-2：文章创建后无法编辑

**当前:** 管理员只能创建和删除文章。如果要修改内容，必须删除后重新创建。  
**建议:** 在文章管理列表加"编辑"按钮，加载已有文章内容到编辑器，保存时覆盖原文件。

### 🟡 F-3：短视频播放体验

**当前:** 使用原生 `<video>` 标签。上传文件存在服务器上，没有转码、没有缩略图自动生成、大视频加载慢。  
**待讨论:** 目前对于 demo 阶段够用，可以考虑支持粘贴视频链接（B站/视频号）自动嵌入。

### 🟢 F-4：Footer 管理链接

**建议:** 如果修复方法选"删除链接"，记得删掉。
