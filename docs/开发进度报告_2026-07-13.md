## 三、Bug 修复记录

| Bug | 根因 | 修复 |
|-----|------|------|
| 管理员无法登录 | 数据库没有 lichaoyi/yulei 账号 | 手动插入 + 删除旧 admin |
| 登录按钮无反应 | DB migrate 时 FOREIGN KEY 冲突导致 getDb() 崩溃 | 加 `PRAGMA foreign_keys = OFF` |
| 登录弹窗"去登录"点不动 | TrialUsageWrapper 守卫锁住模态框 | 全局事件 open-cxl-login 解耦 |
| 陈曦启动失败 | 项目无 venv312，services-config 指向不存在的 exe | 改用系统 Python -m streamlit |
| 数据库 deleted_at 字段缺失 | KUN 旧库无此字段 | 自动迁移逻辑新增 |
| 产品页缺少 'use client' | 导入 motion/react 等客户端库 | 补上指令 |
