## 二、漏洞详情

### 🔴 高危：微信凭证明文泄出

**文件**：`.env.local` 第 41-42 行

```
WECHAT_APPID=wxf013470388ef6ecc
WECHAT_APPSECRET=a185c51f1fbc268dd8a7b6ac35167529
```

**问题**：`.env.local` 文件包含真实的微信应用 ID 和 AppSecret。虽然 `.env.local` 通常被 `.gitignore` 排除，但：

1. 当前目录未确认 `.gitignore` 是否覆盖此文件
2. 如果通过打包/共享/备份等方式泄露，攻击者可用此凭证伪造公众号身份、获取 access_token、读取公众号数据

**严重性**：🔴 高危 — 微信 AppSecret 相当于公众号的密码，泄露可导致账号控制权被盗。

**修复**：
- 此值应从生产环境变量读取，而非写在 `.env.local` 文件中
- 如果已提交到 Git 历史，需立即轮换（在微信公众平台重新生成 AppSecret）

---

### 🔴 高危：instrumentation.ts 子程序启动路径硬编码

**文件**：`.env.local` 第 22-35 行

**问题**：`.env.local` 中硬编码了多个子程序启动路径：

```
CHENXI_EXE=C:\Python314\python.exe
QIAOXI_EXE=D:\Ai RAG\Qiaoxi\venv312\Scripts\streamlit.exe
CXR_EXE=D:\Ai RAG\chengxiaorong\venv312\Scripts\python.exe
```

这些路径指向开发者的个人电脑目录结构。在 `instrumentation.ts` 中如果直接读取这些环境变量启动子进程，且子程序的启动路径包含不受信任的内容，可能导致任意代码执行。但当前路径是写死的常量，无用户输入拼接，所以这是一个信息泄露而非注入漏洞——部署到服务器时这些路径必然失效，需要逐一修改。

**严重性**：🟢 低（开发环境信息泄露，部署时需修改）
