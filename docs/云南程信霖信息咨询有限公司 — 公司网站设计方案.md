## 一、设计理念

### 1.1 核心理念

**专业、可信、现代**

- **专业**：体现金融咨询服务的专业性和严谨性
- **可信**：通过设计细节建立用户信任感
- **现代**：采用现代Web设计趋势，符合目标用户审美

### 1.2 设计原则

1. **内容优先**：设计服务于内容，不喧宾夺主
2. **移动优先**：优先考虑移动端体验
3. **一致性**：全站保持统一的视觉语言
4. **可访问性**：符合WCAG 2.1 AA标准
5. **性能导向**：设计考虑性能优化

### 1.3 目标用户心智模型

| 用户类型 | 设计关注点 |
|---------|-----------|
| **小微企业主** | 专业感、可信度、易用性 |
| **融资撮合门店** | 效率、功能清晰、合作入口明显 |
| **行业协会** | 品牌背书、合作价值展示 |

import { ButtonHTMLAttributes, forwardRef } from 'react'
import { cva, type VariantProps } from 'class-variance-authority'

const buttonVariants = cva(
  'inline-flex items-center justify-center rounded-md font-semibold transition-all duration-200',
  {
    variants: {
      variant: {
        primary: 'bg-gradient-to-r from-success to-emerald-400 text-white hover:shadow-lg hover:-translate-y-0.5',
        secondary: 'bg-white text-gray-700 border border-gray-300 hover:bg-gray-50',
        ghost: 'text-gray-600 hover:bg-gray-100',
        danger: 'bg-error text-white hover:bg-red-700',
      },
      size: {
        sm: 'px-4 py-2 text-sm',
        md: 'px-6 py-3 text-base',
        lg: 'px-8 py-4 text-lg',
      },
    },
    defaultVariants: {
      variant: 'primary',
      size: 'md',
    },
  }
)

interface ButtonProps extends ButtonHTMLAttributes<HTMLButtonElement>,
  VariantProps<typeof buttonVariants> {}

export const Button = forwardRef<HTMLButtonElement, ButtonProps>(
  ({ className, variant, size, ...props }, ref) => {
    return (
      <button
        className={buttonVariants({ variant, size, className })}
        ref={ref}
        {...props}
      />
    )
  }
)

## 八、内容管理设计

### 8.1 内容来源

| 内容类型 | 来源 | 同步方式 | 频率 |
|---------|------|---------|------|
| **公众号文章** | "程信霖融途"公众号 | 手动搬运（初期）→ API同步（后期） | 2-4篇/周 |
| **短视频** | 抖音/小红书 | iframe嵌入/外链跳转 | 实时同步 |
| **深度文章** | 老鬼协议（AI Agent） | 直接发布 | 按需生成 |
| **行业报告** | 内部产出 | PDF上传 | 按需发布 |

### 8.2 老鬼协议

**老鬼协议**是专门用于撰写程信霖深度分析文章的AI Agent，运行在腾讯ima co-pilot平台上。

**核心特点**：
- **专业定位**：专注于程信霖业务领域的深度分析
- **复杂工作流**：拥有多步骤的内容生产流程
- **高质量输出**：产出的深度文章可直接发布
- **署名规则**：与公众号文章一致

**内容类型**：
- 融资行业深度分析
- 信贷产品评述
- 融资避坑指南
- 企业融资案例分析

### 8.3 内容管理架构

```
内容创作流程：
老鬼协议（AI Agent） → 内容审核 → 网站发布
     ↓                    ↓           ↓
腾讯ima co-pilot      人工审核    CMS管理
```

**发布流程**：
1. 老鬼协议生成内容初稿
2. 人工审核确认质量
3. 通过CMS发布到网站
4. 自动同步到公众号（后期）
