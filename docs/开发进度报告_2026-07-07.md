## 二、部署准备：已修复的问题

### 问题 1：前端请求硬编码 localhost
**改动**：3个 AI 产品页面和 2 个 API 路由中的 `http://localhost:8501/8502/8080` 改为通过环境变量读取，同时保留开发默认值。

### 问题 2：环境变量未配置
**改动**：新增 `co-website/.env.example`，记录所有需要的环境变量及说明。部署时复制为 `.env.local` 并填入对应值即可。

### 问题 3：SQLite vs PostgreSQL
**现状**：使用 `better-sqlite3`，部署到自家服务器或 Docker 环境不需要改动。如需部署到 Vercel 等无服务器平台，后续会切换。

### 问题 4：本地文件路径硬编码
**改动**：
- 新建 `src/lib/services-config.ts`，统一管理所有服务配置，从环境变量读取
- `instrumentation.ts` 和 `health/route.ts` 删除全部 `D:\Ai RAG\...` 硬编码路径，改为引用配置模块
- 生产环境不需要这些路径时，不配置相关环境变量即可跳过本地启动

### 问题 5：包依赖
**现状**：`package.json` 依赖完整，`npm run build` 通过。

### 问题 6：build 命令
**现状**：`npm run build` 通过。
