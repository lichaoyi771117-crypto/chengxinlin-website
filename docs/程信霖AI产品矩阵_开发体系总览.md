## 三、各项目核心架构亮点

### 3.1 乔曦（旗舰产品）
- **9-State状态机管线**：客户画像→商业模式解构→风险识别→推演→决策→重构，每步用不同AI策略
- **多Agent架构（1+6+1）**：乔曦（法务助理）+ 6位评审员（记忆物理隔离、一票否决）+ 李超逸（决策者，L1硬编码→L2人格核→L3领域规则三层蒸馏）
- **确定性/非确定性分离**：推演引擎纯Python函数禁止LLM生成结论；决策L1层if-then硬编码不让AI碰
- **25MB本地法规RAG库**：55,088条/1,132部法律，三级处置+来源域白名单
- **4980行Python，13个模块**

### 3.2 峤远
- **峤远主脑协议V1.0**：CFO级四栈专家（财务+税务+融资+法务），六条戒律，Council多角色机制
- **三模型固化**：杜邦分析（Graphviz树状图+单期/双期双模式）+ Altman Z-Score（5分变量）+ Piotroski F-Score（9项信号，单期0-3/双期0-9）
- **25增强指标×7维度动态抽取**：按Q2选择题选择动态路由
- **双版本报告**：专业版7模块+大白话版3段式，共享数据层，模型解释文本固化
- **7行业基准对标**：27指标×颜色评级

### 3.3 程晓融
- **RAG管线**：文档分块→向量化→语义检索→上下文注入
- **程晓融主脑协议V1.0**：四栈专家+六条戒律分析引擎
- **智能上传+AI分拣**：`/smart-classify`接口+关键词匹配分类
- **Prompt工程**：v3→v4迭代，诉讼分析、风险穿透、差距分析

### 3.4 陈曦（设计中）
- **结构驱动 vs 语料驱动**：不走范文库路线，用22种文种的"文体DNA"和"结构铁律"
- **四角色串行评审**：党委办主任→政策研究室→纪委书记→基层执行者，记忆隔离+"必须改"强制修订
- **法规引用三级处置**：5.5万条法规库+来源域白名单+废止法规阻断
- **复用乔曦FSM架构**：工程成熟，开发成本低

### 3.5 程信霖网站
- **Next.js 16 + React 19 + TypeScript + Tailwind 4**（2026最前沿技术栈）
- **68个源文件，17个API路由**
- **试用码系统**：多产品共用一套试用码（程晓融/峤远/乔曦），使用次数追踪
- **StreamlitEmbed组件**：直接嵌入Streamlit应用
- **微信文章转换**：公众号文章→站内文章
- **SQLite WAL模式**：三表（users/trial_codes/trial_bindings）

## 五、关键技术决策记录

### 5.1 主脑协议路线
程晓融和峤远均采用基于楚曦玥V9.3.2改编的主脑协议（六条戒律+四栈专家+Council机制），但各自领域适配：
