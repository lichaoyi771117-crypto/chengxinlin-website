## 二、统一视觉风格 · 必读

生成**每一张图**时，以下指令是铁律。Claude Code 请将其拆解后注入到每个 SD prompt 中，不要遗漏。

### 2.1 风格定义

| 维度 | 要求 |
|------|------|
| **类型** | editorial photography（杂志编辑摄影），不是 stock photo、不是 3D render、不是插画 |
| **情绪** | 沉稳、务实、有温度、有尊严 —— 不是冷冰冰的企业宣传片，不是硅谷创业公司的荧光色 |
| **类比** | Monocle 杂志的摄影 × 中国小企业的真实场景 —— 精致但不浮夸，真实但不出戏 |
| **禁忌** | 西装革履的握手、玻璃幕墙的写字楼、假笑的商务人士、过度打光的棚拍感 |

### 2.2 色彩铁律

```
必须出现的颜色：
  - 深海军蓝 #1a2d4a 及附近色域
  - 铜色/暖金 #c17d4b 及附近色域（暖光、铜色物体、皮革、木纹）
  - 米白/纸白

可以出现的颜色：
  - 低饱和大地色（木色、陶土、亚麻、灰色水泥）
  - 很克制的暗红（仅限印章、文件抬头）

严禁出现的颜色：
  - 荧光色、电光蓝、糖果色、霓虹色
  - 过度饱和的绿色/橙色
  - 纯黑（用深海军蓝代替黑色）
```

### 2.3 光线铁律

```
- 光源：自然光 > 暖台灯 > 窗外光。不用摄影棚灯、不用环形灯。
- 时间感：清晨或黄昏的金色光线。不用正午的硬光。
- 景深：浅景深（f/2.8 左右感觉），主体清晰、背景柔和虚化。
- 阴影：柔和的自然阴影，不是硬切的合成阴影。
```

### 2.4 质感铁律

```
- 哑光表面，微颗粒感（ISO 400-800 的胶片感觉）
- 不要镜子般的光滑反射
- 不要湿漉漉的 HDR 效果
- 能感受到材质的触感：纸张的纤维、木纹的凹凸、布料的纹理
```

### 2.5 构图铁律

```
- 留白要大方，不要塞满画面
- 画面重心偏向一侧（不对称构图 > 居中对称）
- 俯拍或 45° 角 > 正面平拍
- 裁切感（被摄物不完全入画，仿佛杂志排版时有意裁切）
- 画面上方 50-60% 区域留暗色或均匀区域，为文字叠加留空间（适用于带 Hero/Banner 标签的图）
```

### 2.6 严禁事项（所有图共用 Negative）

```
text, watermark, logo, signature, UI, interface, screen content,
smartphone screen with visible apps, laptop with visible desktop,
people in suits and ties, glass skyscraper, stock photo pose,
handshake, thumbs up, fake smile, overexposed, oversaturated,
artificial studio lighting, fluorescent light, ring light,
3d render, CGI, cartoon, illustration, anime, vector art,
unrealistic, low quality, blurry, distorted faces, bad anatomy,
extra fingers, too many people, crowd, busy background
```
