## 一、项目背景

### 1.1 公司简介

云南程信霖信息咨询有限公司，定位为企业融资生态构建者，核心团队拥有10-20年银行及头部金融机构从业背景。公司正在从传统融资撮合向专业融资顾问转型，2026年6月完成业务架构纠偏，形成“流量获客→业务承接→服务落地”的完整闭环。

公司旗下拥有三款AI商业决策产品：
- **乔曦（Qiaoxi）**：AI商业合同审查与决策系统
- **峤远（Qiaoyuan）**：AI财务报表自动分析系统  
- **程晓融（ChengXiaoRong）**：AI融资体检系统

### 1.2 建站目的

1. **品牌展示**：从“融资撮合”向“专业融资顾问”的品牌升级，网站是线上门面
2. **产品入口**：三款AI商业决策产品需要线上展示与使用入口
3. **内容沉淀**：公众号文章、短视频同步到网站，形成内容资产，辅助SEO获客
4. **信任构建**：专业案例、团队背景、行业洞察的集中展示，降低客户决策门槛
5. **获客转化**：通过内容引流→产品体验→咨询洽谈的漏斗，获取有效线索

### 1.3 目标用户

| 用户类型 | 特征 | 需求 | 对应产品 |
|---------|------|------|---------|
| **小微企业主** | 年营收100-500万，5-20人，无专职法务/财务 | 合同审查、财务分析、融资匹配 | 乔曦、峤远、程晓融 |
| **个体工商户** | 年营收50-200万，1-5人 | 简单合同审查、基础财务分析 | 乔曦、峤远 |
| **融资撮合门店** | 线下融资撮合机构，需要提升服务效率 | AI融资体检系统、合作分账 | 程晓融 |
| **行业协会/商会** | 需要为会员提供增值服务 | 合作推广、会员服务 | 全部产品 |
| **代账公司** | 需要提升服务附加值 | 财务分析报告生成 | 峤远 |
| **边境贸易企业** | 涉及跨境贸易，合同复杂 | 多语言合同审查、跨境融资 | 乔曦、程晓融 |

## 三、各页面功能说明

### 3.1 首页

**定位**：第一屏决定用户是否继续往下翻——必须一秒传达“我们是谁、做什么、凭什么是我们”。

**核心模块（从上到下）**：

1. **Hero区**：一句话定位 + 核心行动按钮
   - 主标题示例：“企业融资的体检医生”或“专业重塑资本价值”
   - 副标题：一句话说明核心能力
   - CTA按钮：①“免费融资体检” ②“了解AI产品”

2. **核心痛点区**：3个痛点直击（融资难/选错钱/看不懂报表），每个痛点对应一个AI产品入口

3. **AI产品矩阵区**：三款产品的卡片展示（名称+一句话定位+定价+试用入口），这是首页最重要的转化区

4. **专业服务区**：三大业务板块的简要展示（融资撮合/企业咨询/落地服务），引导至详情页

5. **最新洞察区**：最新3-5篇文章/视频的标题+摘要+缩略图

6. **信任背书区**：核心团队背景摘要 + 合作品牌/协会LOGO墙

7. **页脚**：联系方式、社交媒体链接、备案信息

### 3.2 AI产品页（三个子页面）

**定位**：产品详情 + 在线体验入口。这是网站最重要的转化页面。

#### 3.2.1 乔曦·AI商业合同审查

**产品定位**：国内首个把“能不能签”四个字写进答案的AI商业合同决策系统

**核心功能**：
- 九阶段审查管线：画像校准→条款解析→法规检索→商业模式建模→六维度审计→风险推演→决策输出→合同重构
- 签/改/拖/退四选一决策输出
- 自动生成新合同草案
- 55,088条中国法律法规本地检索

**使用流程**：
1. 上传合同文件（PDF/Word）
2. 系统自动脱敏处理
3. AI分析生成决策报告
4. 下载Markdown/Word报告

**定价**：
- 基础审查：¥20/次
- 高级重构：¥30/次
- 一次完整咨询：¥50/次

**数据安全声明**：
- 本地处理，原始文件不出电脑
- 8类敏感信息自动脱敏
- AES-256加密，WORM审计日志

**合作模式**：
- 推广分账（30-40%）
- 冠名合作
- 联合开发
- 白标嵌入

#### 3.2.2 峤远·AI财务报表分析

**产品定位**：国内第一个把代账会计的Excel翻译成商业判断的AI财务分析师

**核心功能**：
- 自动识别6种中小企业非标Excel格式
- 80+中国会计准则科目映射
- 7大类20+财务指标计算
- 5模块深度解读报告

**使用流程**：
1. 上传财务报表Excel文件
2. 系统自动解析科目
3. 计算财务指标
4. AI生成分析报告

**定价**：
- 标准财务体检：¥20/次
- 融资能力专项：¥30/次

**数据安全声明**：
- 全本地计算，数据不出电脑
- 仅发送结构化指标摘要给AI
- 用户授权协议门禁

#### 3.2.3 程晓融·AI融资体检

**产品定位**：国内第一个站在借款人立场、用合规方式告诉你该往哪贷、为什么的AI融资顾问

**核心功能**：
- 本地OCR解析征信报告（PaddleOCR）
- 昆明本地8大类几十款信贷产品库
- 红绿灯规则引擎自动筛选
- 三层合规自动过滤

**使用流程**：
1. 上传征信报告（PDF/图片）
2. 本地OCR解析
3. 结构化字段提取
4. AI生成融资体检报告

**定价**：
- 免费版：OCR解析+结构化数据提取
- 标准版：完整融资体检报告 ¥20/次
- 企业版：多文件融合分析 ¥30/次

**数据安全声明**：
- 全本地OCR处理，数据不出店
- 仅传脱敏字段至AI
- 满足金融监管“数据不出店”要求

### 3.3 专业服务页

**定位**：展示服务深度和行业认知，不急卖服务，先卖专业。

**内容要点**：
- 按三大业务板块分Tab或分页面展示
- 每个服务：痛点场景→服务内容→交付物→收费模式→合作流程
- 重点突出“融资健康诊断”这一核心服务（生存基石业务）
- 嵌入《融资健康自评简表》作为引流工具

**服务详情**：

#### 融资撮合服务
- **债务协商**：帮助客户与银行协商还款方案
- **信用修复**：协助客户修复征信记录
- **融资规划**：根据客户需求制定融资方案
- **融资撮合服务**：匹配最适合的融资产品

#### 企业咨询服务
- **融资诊断**：分析企业融资能力
- **方案设计**：制定个性化融资方案

#### 企业落地服务

- **系统开发**：定制化系统开发
- **OPC**：一站式企业服务

### 3.4 行业洞察页（内容板块）

**定位**：内容即获客。这是网站的流量引擎。

**功能需求**：
1. **文章列表**：按时间倒序展示，支持按标签/系列筛选
2. **视频嵌入**：抖音/小红书短视频同步展示，支持外链跳转至原平台
3. **专题聚合**：将系列文章打包展示（如“信贷产品深度评述系列”）
4. **搜索功能**：全站内容搜索
5. **标签系统**：每篇文章/视频打标签，支持标签云导航

**内容来源与同步规则**：
1. **公众号文章**：从"程信霖融途"公众号同步，初期手动搬运，后续考虑API自动同步
2. **短视频**：从抖音/小红书嵌入或外链跳转，不做视频托管
3. **老鬼协议**：专门用于撰写程信霖深度分析文章的AI Agent，运行在腾讯ima co-pilot平台上，拥有复杂的工作流程，产出的深度文章可直接发布，署名规则与公众号一致

**内容类型**：
- 深度文章（2000-5000字专业分析）
- 短视频（1-3分钟精华内容）
- 专题系列（系统化知识输出）
- 行业报告（PDF下载）

### 3.5 合作伙伴页

**定位**：B2B渠道合作入口，面向协会、园区、专业机构。

**内容要点**：

| **冠名合作** | 推广方冠名，程信霖品牌隐名 | 有品牌影响力的渠道 | 协商确定 |

## 五、设计风格建议

### 5.1 品牌色系
- **主色**：深蓝色（#1E3A8A）- 专业、信任、稳重
- **辅助色**：金色（#D97706）- 价值、专业、高端
- **中性色**：灰色系（#F3F4F6, #6B7280）- 简洁、现代
- **强调色**：绿色（#059669）- 成功、增长（用于CTA按钮）

### 5.2 字体选择
- **标题字体**：思源黑体（Noto Sans SC）Bold
- **正文字体**：思源黑体（Noto Sans SC）Regular
- **等宽字体**：用于代码/数据展示
- **字体大小**：标题32-48px，正文16-18px，辅助文字14px

### 5.3 布局风格
- **卡片式设计**：用于产品展示、服务介绍
- **大留白**：专业感、呼吸感
- **网格系统**：12列响应式网格
- **圆角设计**：8-16px圆角，亲和力

### 5.4 图标风格
- **线性图标**：简洁、现代
- **填充图标**：用于重要操作
- **统一尺寸**：24x24px或32x32px
- **颜色**：与品牌色系一致

### 5.5 交互设计
- **微交互**：按钮悬停效果、加载动画
- **过渡效果**：页面切换、元素出现动画
- **反馈机制**：操作成功/失败提示
- **引导设计**：新用户引导流程

### 5.6 视觉元素
- **摄影风格**：专业商务场景，真实人物
- **插图风格**：简约扁平化，科技感
- **数据可视化**：图表、仪表盘风格
- **留白使用**：充足留白，避免拥挤

## 六、技术方案建议

### 6.1 前端技术栈
- **框架**：Next.js 14+ (React 18+)
- **语言**：TypeScript
- **样式**：Tailwind CSS + Headless UI
- **状态管理**：Zustand 或 React Context
- **国际化**：next-intl 或 react-i18next

### 6.2 后端技术栈
- **框架**：Next.js API Routes 或独立Node.js服务
- **数据库**：PostgreSQL（主库）+ Redis（缓存）
- **ORM**：Prisma 或 Drizzle ORM
- **认证**：NextAuth.js 或自建JWT

### 6.3 部署方案
- **推荐方案**：Vercel（前端）+ PlanetScale（数据库）
- **备选方案**：Docker容器化部署到云服务器
- **CDN**：Cloudflare 或 阿里云CDN
- **域名**：建议使用.com或.cn域名

### 6.4 第三方服务
- **分析**：百度统计 / Google Analytics
- **表单**：Formspree 或自建
- **邮件**：SendGrid 或阿里云邮件
- **存储**：阿里云OSS 或 AWS S3
- **支付**：微信支付 / 支付宝（如果需要）

### 6.5 开发工具
- **代码管理**：Git + GitHub/GitLab
- **包管理**：pnpm
- **代码规范**：ESLint + Prettier
- **测试**：Jest + React Testing Library
- **CI/CD**：GitHub Actions

### 6.6 性能指标
- **首屏加载**：LCP < 2.5秒
- **交互响应**：FID < 100毫秒
- **视觉稳定**：CLS < 0.1
- **Lighthouse评分**：> 90分

- 技术方案确认
- 内容资产准备

- 页面开发

- 功能测试

- 服务器部署
- 域名配置

- 内容更新
- 性能监控

## 十、风险与应对

### 10.1 技术风险
- **风险**：技术实现复杂度高
- **应对**：分阶段开发，优先实现核心功能

### 10.2 内容风险
- **风险**：内容更新不及时
- **应对**：建立内容更新机制，自动化同步

### 10.3 安全风险
- **风险**：数据泄露、攻击
- **应对**：实施安全最佳实践，定期安全审计

### 10.4 运营风险
- **风险**：用户参与度低
- **应对**：A/B测试，持续优化用户体验
